1 Build a new collection named "Doc and pdf collection"

 
2 In workspace panel, a new collection named "Doc And PDF collection" is built.

 

 
3 Drag documents folder which contain doc and pdf files, into the collectio panel.
 

 

 
4 Check the file details in Documents folder
 

 

 
5 Build Collection
 

 

 
6 Find a error message, during building process, which tell us that "PDF and DOC file can not be processed by any plugin. Next, we will solve this problem.
 

 

 
7 After previewing collection, we find doc and pdf files parsed unsuccessfully, except the PS files.
 
8 Click the file menu, and choose the "Reference"
 

 

 
9 Choose the "Mode" navigational tab, and check "Expert" choice. By this way, we enter into the expert operation mode.
 

 

 
10 After rebuilding collection, under the expert mode, we find that because system can not find "cmd.exe" files, the problem occures.
 

 

 
11 Go into C disk, and search "cmd.exe" file.
 

 

 
12 Copy cmd.exe file into the folder of "C:\Greenstones\bin\windows"
 

 

 
13 Rebuild.
 

 

 
13 Preview. It is succussful to process and parse whatever doc or pdf files.
 

 

 
14 Click the "Enrich" navigational tab, and choose cluster.ps file from left panel. There are two kinds of elements in right panel. The first kind is openning with dc, which means dublin core. The second kind is openning with ex, which means extraction.
 

 

 
15 Not all of the file are parsed correctly. Word03.doc is the example. Its title is not much more correct, because ex.Title lost the second title line.
 

 
16 The title of word03.doc
 

 
17 Type the dc.Title by hand.
 

 
18 Type author name in dc.Creator
 

 
19 Press enter, and type more co-author name information.
 

 
20 During parsing process, we employed merely serveral plugins.
 

 
21 Remove the ex.Source, because it has no big use in this demonstration
 

 

 

22

 Edit ex.Title.
 

 
23 Concurrently check the dc.Title box and ex.Title box, then click replace button.
 

 
24 Assigned indexes has been changed into "dc.Title,ex.Title"
 

 
25 Click "New Index" button
 

 
26 Check dc.Creator box, then click "Add index" button.
 

 
27  
 

 
28 Choose "Design" navigational tab, remove the "AZList -metadata ex.Source" classifiers from "Assigned Classifiers" panel.
 

 
29 Configure "AZList -metadata ex.Title" Classifiers.
 

 
30 From drop down menu, choose dc.Title item.
 

 
31 "AZList -metadata ex.Title" has been changed into"AZList -metadata dc.Title".
 

 
32 In order to create compact list, choose "AZCompactList" item, then click "Add Classifiers" button.
 

 
33 From the drop down menu, choose "dc.Creator" item.
 

 
34 A new assigned classifiers named "AZCompactList -metadata dc.Creator" has been added.
 

 
35 Rebuild collection.
 

 
36 Preview. Because I just enter the "dc.Title" and "dc.Creator" on two files, only two files displayed here when I click titles.
 

 
37 There are four authors compact list displayed.
 

 
38 When clicking the "Search in" drop down menu, there are two choices named "dc.Title,Tile" and "dc.Creator".
 

 
39 Click the "Format" navigational tab, and change the display text.
 

 
40 Change the "dc.Title, Title" into "Title". And, change the "dc.Creator" into "Creator".
 

 
41 Go back to preview, the items in "Search in" drop down medu has been changed.
 

 
42 Click the "Design" naviagational tab, and configure the classifiers of "AZList -metadata dc.Title".
 

 
43 Type ex.Title following dc.Title, and use coma to separate them.
 

 
44 Click the "Design" naviagational tab, and configure the classifiers of "AZCompactList -metadata dc.Creator".
 

 
45 Type ex.Creator after the dc.Creator.
 

 
46 Rebuild collection
 

 
47 Preview in titles.
