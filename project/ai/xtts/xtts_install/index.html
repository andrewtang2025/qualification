  1 What is Xtts?
   

XTTS is an open-source, multilingual AI text-to-speech model that performs zero-shot voice cloning. It can synthesize natural-sounding speech in a speaker's voice using only a short reference audio sample, without requiring additional model training.

XTTS is:

  • AI voice cloning software
  • Neural text-to-speech system
  • Zero-shot voice cloning model
  • Multilingual voice cloning model
  • Speech synthesis model

  • What "zero-shot" means:

    XTTS is often called a zero-shot voice cloning model because it can clone a person's voice from only a short reference recording (around 3–30 seconds) without additional training.Unlike older systems that required hours of recordings and model training, XTTS can generate speech in a new voice almost immediately.
