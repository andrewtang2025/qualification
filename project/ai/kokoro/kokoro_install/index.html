  1 What is Kokoro?
   

Kokoro TTS is an open-weight, highly efficient Text-to-Speech AI model that creates natural-sounding human voices from written text. Developed by hexgrad, it gained massive popularity in the open-source community because it achieves elite audio quality despite being incredibly small.

Key Features
  • Tiny Architecture : It uses only 82 million parameters . While massive commercial models require powerful cloud servers, Kokoro is under 2 GB and can run locally on consumer hardware, including laptops and mobile phones.
  • High Quality and Speed : Despite its small footprint, it produces clean, human-like speech that ranks near the top of public TTS Arenas , beating many expensive commercial APIs. It generates audio faster than real-time speed.
  • Multilingual Support : It natively supports languages such as English, French, Japanese, Korean, and Mandarin Chinese.
  • Permissive Licensing : It is released under an Apache 2.0 license . Anyone can use it for free, self-host it, modify it, or deploy it in commercial products without paying licensing fees. [1, 2, 3]
  • Advanced Controls : Users can combine different voice profiles together (voice blending) or use precise IPA (International Phonetic Alphabet) markup to manually correct the pronunciation of unique names or technical words.
Developers and creators frequently use Kokoro TTS for:
  • Audiobooks and Podcasts : Turning entire books or scripts into high-quality spoken audio locally without cloud costs.
  • Local Voice Assistants : Pairing it with local Large Language Models (LLMs) to create immediate, low-latency conversational AI companions.
  • In-Browser Apps : Using tools like WebGPU and WASM, it can run directly inside web browsers with zero server-side uploads, keeping user voice processing entirely private.
